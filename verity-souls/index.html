What to do before installing anything called Verity Souls

Wait for a source page with real install metadata

A safe Verity Souls download route should look boring and specific. It should name the platform, owner, package type, game version, loader, file record, version ID, changelog, dependencies, and setup requirements. For Java, expect a JAR route and loader matching. For Bedrock or MCPE, expect MCADDON or MCPACK behavior. For a modpack, expect a launcher profile package or platform-managed install. If a page skips those details and only promises the "real Verity Souls mod," the source evidence is too weak.

The same rule applies when someone shares a Google Drive, MediaFire, Mega, Discord attachment, password ZIP, EXE installer, APK, or shortened URL. Those links may be shared by excited players, but they remove the source context a searcher needs. A file name can be copied. A screenshot can be staged. A video caption can be wrong. A project page with stable metadata is much stronger evidence than a repost.

Use a route checklist instead of a rumor checklist

  1. Identify the edition first: Java, Bedrock, MCPE, or modpack.
  2. Identify the host: CurseForge, Modrinth, MCPEDL, Google Play, or another site.
  3. Record the owner and Project ID when the host exposes one.
  4. Match the package type to the edition before downloading.
  5. Keep API keys and voice setup separate from file-source identity.

This is stricter than most video comments, but it saves time. If the route is real, the metadata will line up. If the route is only a rumor, the checklist will show the missing parts quickly. That is the safest answer for Verity Souls until an official source page appears.

What would be enough to change the status

The status should change only when a source controlled by the project owner exposes concrete release evidence. A good signal would be a CurseForge, Modrinth, MCPEDL, official website, or official creator post that points to the final project page and names the package route. The record should show whether Verity Souls is Java, Bedrock, MCPE, a launcher modpack, or a different format. A weak signal would not be enough. A reuploaded JAR, a Discord file attachment, a cropped screenshot, a password ZIP, a "download now" mirror, or a video caption without source metadata would still be treated as unverified. The point of the Verity Souls page is to protect searchers from moving too fast when a new name starts trending.

How to compare a future release with existing routes
