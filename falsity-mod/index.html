Route separation

Which page should you use?

You searched "Falsity Mod"

First decide whether the result is Java or Bedrock. The PKFL FALSITY [SMILEY] route is a Java Forge mod, so the expected package is a JAR and the expected launcher path is a Forge 1.20.1 profile. The MCMOBZ Falsity Mod route is a Bedrock add-on, so the expected package is an MCADDON and the expected setup is a Bedrock or MCPE import. If the result gives you an APK, EXE installer, password ZIP, shortened URL, or generic "all editions" package, treat it as a separate claim until it can be traced back to the publisher page.

Falsity uses some of the same search language as Verity because players discuss it as a related horror companion and because recent videos describe it as a Verity sequel or variant. That does not make the download interchangeable. If a tutorial says Falsity and the page says Project ID 1575216, do not replace it with Verity JE. If a tutorial says Verity JE or verity-5.7.3.jar, do not replace it with FALSITY [SMILEY].

You searched "Verity Mod"

Use the Verity route map first. Java players should verify Verity JE, the stable verity-5.7.3.jar route, Minecraft 1.20.1, Forge, and the Java dependencies. Bedrock and MCPE players should verify Verity BE, PnTMC, or Pocket Edition package records. Falsity can be a relevant related result, but it is not the base Verity Mod download answer.

The safest search behavior is to decide edition before file name. A Java JAR does not import into Bedrock. A Bedrock MCADDON does not go in a Java mods folder. A modpack ZIP is a profile route. A Falsity JAR should be compared to the Falsity project, while a Verity JAR should be compared to the Verity JE project.

Setup and errors

Do not turn provider setup into a download problem

Commands and configuration are route-specific

The FALSITY [SMILEY] description exposes route-specific commands such as /connectfalsity, /falsitysetup, and /falsityconfig. Those are not universal Verity Mod commands. Verity BE, PnTMC Bedrock, Verity JE, and VERITY.exe have their own control and setup assumptions. Copying commands across projects is one reason players think the mod is broken even when they installed the wrong route.

If a command is missing, first prove that you installed the project that documents that command. Check the source page, Project ID, file ID, Minecraft version, and loader. Then test in a clean profile or clean world before adding other horror packs, shaders, resource packs, or server-side plugins.

AI, voice, and microphone features need their own checks

The Falsity project page describes optional external LLM, text-to-speech, and speech-to-text provider support, including OpenAI-compatible APIs, Gemini, Groq, Ollama, OpenRouter, and Whisper-compatible transcription. That means an API key, microphone, voice, or provider error can happen after the mod file itself is correct.

Do not paste API keys into random download pages, comments, or forms. Configure keys only in the game or provider flow that the project documents. If voice fails, prove typed chat first. If typed chat fails, prove the provider and config route. If the provider returns 401 or 429, use the API error pages instead of replacing a valid Falsity or Verity file with a mirror.

FAQ

Falsity Mod questions

Is Falsity Mod the same as Verity Mod?

No. FALSITY [SMILEY] is a separate CurseForge Minecraft Mods project by PKFL. It can appear in the same trend as Verity Mod, but Verity JE, Verity BE, PnTMC, VERITY.exe, and Verity Pack are separate routes with separate package types.

What file should I see for the current Falsity route?

At this check, the source page showed FALSITY-SMILEYARCHIVE-9.0.jar, file ID 8528006, uploaded Jul 28, 2026, for Minecraft 1.20.1 Forge. If a page gives a different package type, use the link checker before opening it.

Is there a Bedrock Falsity Mod?

Yes, but it is a separate fan-made Bedrock remake route. The current check found a CurseForge Minecraft Bedrock Addons page by MCMOBZ, Project ID 1594973, with file Falsity_2_0_0_Addon_updated.mcaddon, file ID 8449365, for Bedrock 26.30. Use it only when you want a Bedrock or MCPE add-on, not the Java FALSITY [SMILEY] Forge JAR.

Is the Falsity Mod on Modrinth too?

Yes. The source check found Modrinth project r8Qz0Ic2 and version tNOLeN6v for FALSITY-SMILEYARCHIVE-9.0.jar. The Modrinth version record includes SHA-1 and SHA-512 hashes, so the homepage checker can recognize that publisher fingerprint.

What do /connectfalsity, /falsitysetup, and /falsityconfig do?

The current public description says /connectfalsity changes Falsity language, /falsitysetup sets a custom companion name, and /falsityconfig opens the configuration menu for optional AI, TTS, and STT providers. These are Falsity route commands, not universal Verity Mod commands.

Does Falsity need an API key?

The source page describes external AI, TTS, and STT providers as optional and says the mod can use built-in local behavior systems and packaged voice lines by default. If you enable external providers, use your own provider dashboard and never paste keys into public pages.

Should I install Survive from VERITY or FALSITY instead?

Only if you intentionally want that CurseForge modpack profile. It is a separate route by kanthbuymi, Project ID 1583260. It is not the same as the standalone FALSITY [SMILEY] mod, Verity JE, or a Bedrock add-on.
