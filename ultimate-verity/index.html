Install decision

Choose a package type first, then a file

If you want the Ultimate VERITY modpack

Use the Julian_moto CurseForge route and confirm the source fields. The project should show Project ID 1584643, Modpacks as the class, Minecraft 1.20.1, Forge, and the main file Ultimate VERITY.-1.20.zip. The file page records file ID 8467605, 3.3K file downloads, a 99.8 KB size, and release type R. The description also says it did not create the underlying Verity project, which is exactly why the route should not be treated as the default standalone Verity file.

That does not make the page useless. A player who wants a prepared horror survival profile can use it. A player who needs the Java JAR should not. If your real problem is an API key, no response, voice setup, or the helper not appearing in a clean Java profile, open the Java or troubleshooting route first. Installing a full modpack can hide the original setup problem.

If you found Ultimate Verity Horror

That is a different CurseForge modpack by Alfredo420, Project ID 1616028. The public page exposes a NeoForge 1.21.1 main file, file ID 8464466, and a Forge 1.20.1 file, file ID 8461753. Its description describes a yellow sphere companion that changes after four in-game days and includes setup notes copied into the profile description. Treat it as a separate profile, not as proof that the normal Verity JE record changed.

If a video or comment only says "ultimate verity horror", ask which Project ID it links to. Project ID 1584643 is the Julian_moto Ultimate VERITY route. Project ID 1616028 is the Alfredo420 Horror route. Similar titles can still be legitimate source pages, but they answer different install jobs.

If you found the Bedrock Skinpack

Ultimate Verity Skinpack is not a behavior add-on. The CurseForge Bedrock page lists Project ID 1599807, category Skins and Skin Packs, supported game versions 26.30 and 26.20, and UltimateVeritySkinPack.mcpack, file ID 8472780. It can change the player's look, but it does not replace Verity BE, PnTMC, Java Verity JE, or a server-side setup.

This distinction matters for mobile searchers. A Bedrock user can import an MCPACK and still have no AI companion, because a skin pack is only cosmetic. For actual gameplay behavior, use Bedrock add-on routes and confirm behavior pack activation, resource pack activation, Beta APIs, cheats, and the clean-world test.

FAQ

Ultimate Verity questions

Should I install Ultimate VERITY instead of Verity JE?

Only if you want the whole modpack profile. Verity JE is the standalone Java route. Ultimate VERITY is a separate profile with its own project owner, Project ID, file ID, and profile assumptions.

Why does Ultimate VERITY link to an old verity-mod page?

The project description points bug reports to an older standalone-mod URL. That does not mean a mirror is safer. It means the modpack is separate from the source route it references. Use the current Java route or the taken-down guide when old links return 404.

Can I use Ultimate Verity Skinpack for Bedrock gameplay?

Use it only for skins. For gameplay behavior, install a Bedrock add-on route such as Verity BE or PnTMC and follow the world setup checklist.
