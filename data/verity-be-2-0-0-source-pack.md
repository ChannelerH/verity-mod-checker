## Setup facts to preserve

The official Verity BE page says players need the Bedrock add-on setup flow, not only a file import. A useful support answer should cover:

- Import the current `mcaddon` once.
- Activate both behavior pack and resource pack.
- Use Minecraft Bedrock 26.30 when following the current Stable 2.0.0 route.
- Enable Beta APIs under Experimental Toggles.
- Enable cheats when the setup or support route requires commands.
- Run the current debugger connect step if the maintainer tutorial or Discord support requires it.
- Talk to Verity by typing `Verity` before the message.
- Test in a clean world before changing files.
