FAQ

Questions players ask about the PnTMC 3.2.0 route

Is this page an official Verity or PnTMC download?

No. This is an independent source-check page. It does not host the file, mirror the MCADDON, or claim ownership of Verity. Use the linked maintainer pages for the final download and support context.

Why does the page mention MCPEDL if CurseForge has the exact record?

Many MCPE players discover this route through MCPEDL or video descriptions, not through a direct CurseForge record number. MCPEDL is useful as a route clue because it identifies PnTMC and the Bedrock project, but the exact CurseForge record is the better stable identity signal when the visible download rows are out of sync.

Does a matching record prove the file is safe?

No. A record match proves route identity, not a malware verdict. It helps you avoid wrong-edition files, stale mirrors, or random hosts. You still need normal device safety practices and should avoid any page that hides the final host or wraps the add-on in unrelated installers.

What should I do if Verity does not spawn after installing 3.2.0?

First confirm you installed the PnTMC route and not Verity BE or a Java JAR. Then test in a clean world, activate behavior and resource packs, enable required experiments, and read the not-working and talk-control pages for project-specific steps.

Why do MCPEDL comments say Verity does not reply or never transforms?

Current public comments on the MCPEDL route still include no-reply, no-monster-form, and not-spawning reports. Treat those as setup symptoms first, not proof that the file record is wrong. Check that the behavior pack and resource pack are both active, Beta APIs or required experimental toggles are enabled, your world is not carrying an old conflicting pack, and you are following the PnTMC route rather than Verity BE or Java JE advice. If the file identity is right but the behavior still fails, use the PnTMC YouTube/community feedback path named in the project description, because the maintainer says feedback there is easier to read.
