Decision

Do not use the Vercel page as a Verity Mod install source

The problem is missing source proof, not just the hosting platform

A Vercel subdomain is not automatically bad. Many legitimate projects use Vercel for demos, documentation, or prototypes. The problem with this Verity Mod page is that the download claims are separated from the project records a player needs before installing a Minecraft mod. A strong Java route should preserve a Modrinth project ID, version ID, file name, loader, Minecraft version, file size, and hash. A strong CurseForge route should preserve the project ID, file record, owner, supported game version, and file history. A Bedrock route should preserve the add-on project and MCADDON record. The Vercel page instead presents a generic landing page with a button and broad loader labels.

That distinction matters because fake Verity Mod pages benefit from the same urgency that makes the keyword valuable. A player sees a viral video, searches for a quick download, and clicks the first page that looks like a product site. If the page hides the final source, the user cannot compare the download against the maintained Java or Bedrock route. The safer answer is slower: match the publisher record first, then download from the source page only when the edition, loader, package, and version all line up.

The July 30 search checks make this more than an abstract warning. Google showed official Modrinth, CurseForge, Google Play, YouTube, Fandom, and app-style results for broad Verity Mod discovery. Bing showed CurseForge first, then surfaced verity-mod.vercel.app before other discovery pages. That is exactly the moment where a player needs a source check: the landing page is visible enough to attract clicks, but it does not give the route identifiers that would let a user confirm the file before running it.

verity-mod.vercel.app questions

Is verity-mod.vercel.app a virus?

This page cannot scan a remote download and should not pretend to. The stronger statement is that verity-mod.vercel.app did not provide the source proof a Minecraft player needs before installing: no checked project ID, no file record, no version ID, and no checksum in the visible page text. Because Google search showed a warning interstitial and a reputation report classed the domain as suspicious, the sensible action is to avoid using it as a download source.

Why not just trust the 2.4M downloads claim?

A number on a landing page is not the same as a platform counter on Modrinth, CurseForge, or MCPEDL. Current source checks can trace Modrinth Verity JE counts, CurseForge Verity JE counts, Verity BE counts, PnTMC counts, and Pocket Edition counts to project pages. The Vercel page did not show a source trail for its 2.4M+ claim at the check.

Why did this page get refreshed after the Bing check?

Because Bing currently places the Vercel page inside the visible main-result set for broad Verity Mod discovery. That is a user-demand signal: players can find the Vercel page before they know whether Verity Mod means Java, Bedrock, MCPE, an Android app, a video tutorial, or a copied file. The refresh adds current search context and official route records so the page solves that decision faster.

What if a YouTube video links to the Vercel page?

Treat the video as a clue, not as the source of truth. Search the project name on Modrinth or CurseForge, compare the loader and Minecraft version, and use the route checker before installing. If the video says Fabric 1.21.x but the checked project route says Forge 1.20.1, do not mix those instructions in the same launcher profile.

Can I use this page as a Reddit answer?

Yes, when a player asks whether the verity-mod.vercel.app link is official, the useful answer is not a one-word panic reply. Tell them the page lacks traceable project records, then point them to the current Modrinth Java route, the CurseForge comparison route, or the Bedrock route that matches their edition. Do not tell people to run the file "to see what happens."
