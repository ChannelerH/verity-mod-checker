Fast routing rule

Do not choose by title alone

Choose by package type and route context. A `.jar` belongs to a Java loader profile. A `.mcaddon` belongs to Bedrock or MCPE. A `.zip` can be a modpack profile. API and voice errors usually mean the file already loaded and the next check is configuration, not a new download.

  1. Need the current file? Open the download map or exact file page.
  2. Need to play, talk, spawn, or add friends? Open the play or server route.
  3. Need to fix status 401, 403, 429, dots, voice, or no response? Open the symptom route.
  4. Need to cite data? Use the creator reference, release JSON, or update feed.

Intent groups

Choose the page by the problem a player is actually trying to solve

DOWNLOAD

Downloading or verifying a file

Use download routes when the user has not opened Minecraft yet, or when the search phrase names a file, version, Project ID, CurseForge page, Modrinth page, MCPEDL row, APK, EXE, or mirror. These pages answer whether the route is Java, Bedrock, MCPE, a modpack, stale, current, or unsafe to trust without more context.

PLAY

Playing, talking, spawning, or joining friends

Use play routes after the user knows the edition but does not know how the project behaves in a world. These pages separate first-session testing from source selection. They help users decide what to type, what to activate, how to spawn, how to use a server, and why a console or mobile route cannot use a Java folder.

FIX

Fixing errors after launch

Use fix routes when Verity loads but does not reply, crashes, only shows dots, returns a provider status code, speaks silently, stutters, or fails to appear. In these cases the best answer is usually edition, pack, provider, model, quota, microphone, or clean-world diagnosis. Replacing the file first often creates a second problem.

Route FAQ

Why this index exists

Why not put every answer on one page?

Searchers use the same phrase for different jobs. One person wants the stable Java file. Another has already installed a Bedrock add-on and only sees dots. Another is trying to talk to Verity through a microphone, join with friends, import on MCPE, or decide whether an APK is safe. A single generic answer would force most readers through irrelevant steps. This index gives Google and players a clean map to the most specific page.

Does this page replace the XML sitemap?

No. The XML sitemap remains the machine-readable crawl list, while this route index is a human-readable directory with context. The sitemap tells crawlers that a URL exists. This page explains why a page exists, when to use it, and how it differs from nearby pages.

What should a player check first?

Check edition first, then package type, then source page. Use Java pages for JAR and loader issues, Bedrock pages for MCADDON import and world settings, play pages for in-world behavior, and fix pages for provider, voice, status-code, no-response, and performance symptoms.
