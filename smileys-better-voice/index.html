Smiley's Better Voice for Verity JE

Smiley's Better Voice is a separate Verity JE add-on for players who want more expressive text-to-speech, Fish Audio or Cartesia voices, and optional voice mimicking. Setup order

Install and test in layers

Layer one: parent mod and loader

Start with a clean Java profile. For the current Better Voice file, the checked route is Minecraft 1.20.1 Forge. The current file changelog says Better Voice 4.0.0 adds support for Verity JE 6.0.0 and is incompatible with earlier Verity JE versions. The broader project table may still show older requirement wording, so treat the exact file page as the current compatibility source. For older rows, treat the files/all table only as a pointer: open the exact old file page, match Minecraft version and loader, then decide whether that parent/add-on pair is worth keeping. Add only the needed parent mod and dependencies first. Launch the profile and confirm the game opens before adding extra horror packs, server-side utilities, visual mods, or provider experiments. This protects you from diagnosing a sound issue when the real issue is a loader, dependency, or version mismatch.

After the parent Verity JE route loads, test one short typed prompt. If the text response fails, check Groq, Ollama, OpenRouter, status 401, status 429, local server state, or model behavior. If the text response works but voice does not, Better Voice, Minecraft audio, TTS provider, voice ID, internet access, or provider credits become the likely layer.

Layer two: Fish Audio

Fish Audio is the quality and emotion path. It uses its own API key and a voice or reference ID. Voice mimicking also belongs to this side. If the mimic fails, the checked project notes point to common causes such as invalid Fish key, insufficient credits, or not enough clean push-to-talk speech. Do not post the Fish key, the full voice ID, or a private audio sample when asking for help.

Layer three: Cartesia

Cartesia is the speed and pronunciation path. It has its own API key and Voice ID in a separate config tab. If a player changes providers and Verity becomes silent, confirm that the provider was actually switched, the right tab has a key and voice ID, Minecraft is online, and the account has access to the selected voice. Do not reuse a Groq key in a Cartesia field.

Layer four: audio output

When chat works and provider settings look right, check ordinary output. Raise Minecraft master volume, voice or sound sliders, operating-system output, headset routing, resource packs, and server/client parity. If the player is on a server, confirm the add-on and dependencies are present where the feature expects them. A working text response means the problem may be after the AI layer.

Key and voice safety

Do not expose provider secrets while asking for help

Useful support summaries avoid private data

A good Better Voice support message should name the route, Minecraft version, loader, parent Verity JE version, Better Voice file record, selected provider, whether typed text works, and the exact non-secret error text. It should not include a Fish API key, Cartesia API key, Groq key, Ollama endpoint credential, OpenRouter key, full voice ID, session token, or private audio sample. If a helper asks for a full key in public, stop and move to a safer support channel.

Voice mimicking deserves extra care because it can involve captured speech. The checked project page describes Fish-based mimics as private to the player's Fish account and stored server-side for multiplayer. That is not a reason to panic, but it is a reason to avoid public uploads of voice samples, log files containing account data, or screenshots that show provider dashboards.

Copy this safe support outline

  • Project: Verity JE plus Smiley's Better Voice.
  • File: Better Voice record 8536538 or another exact record.
  • Minecraft and loader: for example 1.20.1 Forge.
  • Parent version: Verity JE 6.0.0 for current Better Voice 4.0.0, or the exact older match.
  • Provider: Fish Audio or Cartesia, without the key.
  • Text test: whether Verity JE replies in chat before voice.
  • Audio test: whether any Minecraft sounds and other TTS output work.
  • Error: sanitized toast or log line with secrets removed.
